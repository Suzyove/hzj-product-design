智能香薰机研发

GRACIANA 智能香氛硬件 / 2025

消费电子结构研发场景渲染

配合香薰精油品牌开发的便携智能香氛设备。从竞品调研与场景痛点分析出发， 确立"便携+多场景"差异化方向。主导概念草图推敲、按键交互逻辑与透光件 氛围灯细节定义，经多轮造型迭代后进入打样验证阶段，同步输出桌面、室内、 露营等多场景渲染，同时拓展至车载香薰机和大容量香薰机的造型研究与开发。

A 调研与竞品分析

调研市面常见的家居香氛设备，确定"便携+多场景"差异化方向。

USER INSIGHT · 场景痛点

车载香薰固定在出风口、桌面扩香器离不开插座——市面产品普遍缺少 「移动性」。用户需要一款可手提、可桌面、可户外的 便携香氛设备，让香氛跟随场景自由切换。

02

足浴器产品改款

小家电 · 自有品牌选品改良 / 2026

小家电自有品牌选品外观与 CMF 改良

为品牌自有产品线完成选品与改良设计：在合作工厂的白牌功能平台（蒸气加热、水泵循环、按摩盘模组）上选定基础机型， 沿用成熟功能模块与分模逻辑以控制开模成本，重新定义形态语言、交互布局与 CMF 体系—— 把一台「工厂标准品」改造成能进家庭的自有品牌产品。

A 原款诊断与设计输入

选品基础机型为合作工厂的现有平台款足浴盆（蒸气加热 · 水电分离 · 泵循环按摩）。诊断四个核心问题：控制面板外凸、两侧造型碎裂；配色暗沉（灰底机身 + 黑色按摩盘）；旋钮按键排布老气、无品牌感；整体体量笨重。

REDESIGN BRIEF · 三条改良目标

① 去医疗感 → 家居化

冷灰蓝 + 卡通贴纸的医疗器械感，转为暖米白主色，让产品能放进客厅与卧室。

② 整合交互 → 隐藏面板

外露双显示屏 + 圆形旋钮信息繁杂，收敛为隐藏式一体触控指示区。

③ 一体包覆 → 减少视觉零件

碎裂式多件外壳整合为大面连续曲面，视觉零件数最小化，提升精致感。

B 形态重定义

保留内部功能模块、水路与分模逻辑不变，仅重做外壳比例与顶面语言——把原款「碎裂化外壳」收敛为一个完整的一体包覆体块，控制面板沉入上盖轮廓线，机身侧面完整连续。

C 结构拆解

整机爆炸与透明视件渲染：按摩盘组、泵体、加热模组、底座脚轮的装配关系一目了然——功能模组沿用工厂的成熟方案，外观与交互件全部重新定义。

D CMF · 色彩 / 材质 / 工艺

配色聚焦一套主色——暖橙×米白（活力家用）：暖橙定义可动的盖体与交互件，米白一体包覆整机主体，深棕只落于底部脚轮，整体亲和、适配居家环境。

03

水晶项链众筹上线项目

GRACIANA 葛蕾莉雅 / 深圳 / 2024 — 2025

产品全流程水晶工艺众筹上线

从市场调研、竞品分析出发，定义"随身香氛首饰"品类。以水晶刻面工艺塑造苹果形态， 寓意平安如意。经历概念草图推敲、五金件结构定义、多轮造型迭代后进入工厂打样量产， 并完成 CMF 色彩材质规范与礼盒包装设计。众筹上线达成率 530% （566 人支持，目标 2 万元 / 实际 10.6 万元），主导众筹页面视觉与推广内容。

A 市场调研与竞品分析

调研市面水晶饰品与随身香氛品类，确定"随身香氛首饰"差异化定位。

USER INSIGHT · 用户痛点

传统精油使用场景局限于室内扩香或随身瓶，缺乏可佩戴、可社交展示的载体。 市面水晶饰品以纯装饰为主，无功能承载。将水晶刻面工艺与精油瓶芯结合， 定义"随身香氛首饰"——既有饰品社交属性，又解决精油随身使用的真实需求。

B 概念草图与结构推敲

从苹果形态到刻面切割，蝴蝶结金扣内嵌精油瓶芯的结构方案推敲。

C 造型迭代与系列化

从苹果水晶造型到领结五金结构件敲定、从光滑到刻面的水晶工艺——多轮造型迭代形成系列 SKU。

D 量产上线与礼盒

与工厂深度协作完成打样、工艺确认与质量把控，上线众筹并完成礼盒套装视觉。

  • 主体天然水晶 · 刻面切削工艺
  • 五金锌合金电镀 · 蝴蝶结扣
  • 结构内置精油瓶芯 · 可用滴管补充精油
  • 众筹达成率 530% · 566 人支持
